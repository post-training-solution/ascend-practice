# 峰值算力

规则：峰值用官方规格中的 **BF16 稠密**值（不用稀疏峰值）。用 `npu-smi info` 确认子型号后再取值，并在结果里写明来源。下表只汇总已见到的第三方取值。各来源之间互相矛盾，**都不能直接当作官方值**，只能作为核对线索。

| 芯片 | verl `_DEVICE_FLOPS` | 官方 BF16 稠密 | 备注 |
| --- | --- | --- | --- |
| Ascend910（一代） | 354 | 待核实 | 两个来源差异很大 |
| 910B（未分子型号） | 354 | 待核实 | |
| 910B1 | — |  待核实 | |
| 910B2 | — |  待核实 | |
| 910B3 | — |  待核实 | |
| A2G3 | 354 |  待核实 | |
| 910C（A3，整芯片双 die） | — |  待核实 | 按 die 计时还要除以 2，需确认 |
| Ascend950DT（A5） | 432 |待核实 | |

核实一项，就在“官方 BF16 稠密”列填上数值，并在备注里写明出处（规格书名称和版本）。
